## Decisions and constraints

- The goal was marked blocked rather than falsely completed.
- Default-off switches use `setting_opt_in` (absence means off); ordinary toggles
  keep `setting_enabled`.
- AI sends only what the disclosure copy says: URL/title, optional visible page
  text (≤20k chars) when `ai_page_context` is on, ten-turn history, question.
  The API key lives in the login Keychain, scoped by profile.
- Sync is folder/iCloud Drive, last-writer-wins with union/max merge; not CloudKit.
- Extensions are the WebKit WebExtensions subset; no native messaging host.
- Passkeys are documented but not enabled without Apple's entitlement.

## Blockers and open questions

1. **#64 VoiceOver:** GPUI 0.2.2 exposes no accessibility tree. Need either an
   approved GPUI/AccessKit upgrade or an upstream release with accessibility.
2. **#14 Mac IME:** needs a real Mac with a Japanese/Chinese input source; the
   Linux/CI environment cannot observe it.
3. **#186 login hardening:** needs real-Mac evidence for Keychain prompts,
   synthetic input boundaries, and duplicate Save/Replace decisions.
4. **#190 residuals:**
   - Passkeys need `com.apple.developer.web-browser.public-key-credential` and a
     matching provisioning profile.
   - iCloud/CloudKit sync needs an iCloud-capable signed build/container.
   - Chrome native messaging needs a Safari app-extension/native-host component.
   - Extension badges and some runtime parity remain.
5. **Handoff receive** is hardware-unobserved.
